# 东盟应急项目试点

把东盟应急科技挑战赛的参赛项目组织为**跨国本地试点产品**：描述台风洪涝等获奖项目从竞赛结果到某国限定站点真实值守之间的适配、授权、演练、运行边界与扩大推广规则。所有机构、人员、站点、台风与编号均为虚构样例，不含真实个人信息、账号、密钥或连接凭据。

## 核心业务规则

- **获奖不是许可**：`award.won` 与部署许可完全独立登记；进入真实值守只看本地准入。
- **七类组件各自版本化**：技术能力、训练数据边界、设备依赖、部署地点、责任机构、演练脚本、验收指标，任一变更只升自身版本，不联动其他组件、不自动改变准入结论。
- **四项准入缺一不可**：本地化评审、数据授权、人员培训、回退方案，每项都要 `passed=true` 且有证据编号和评审机构；缺一项不得进入真实值守，声明状态与准入事实矛盾会被拦截。
- **自动降级必须留痕**：网络中断、传感器漂移、置信度下降触发 `autonomous → assisted → advisory_only → manual` 降级；多触发并存取最严模式；只要降级就必须有字段完整的人工接管记录。
- **跨境只共享获准摘要**：载荷字段必须同时在该国出境白名单和产品摘要字段内，原始站点数据等禁出字段一律拦截；跨国只传递严重度 `rank`，不传递任何一国本地等级代码。
- **各国独立、UTC 为准**：所有时间先后只按 `at_utc` 判断，本地时间仅展示；台风事件必须按形成→逼近→登陆→洪涝→灾后推进；一国撤回即时冻结本国扩大推广，不影响他国。
- **扩大推广只认证据**：主办方只能凭决策前的合格真实演练（和后续运行证据）扩大推广；资金里程碑、多方签署、主办方意向均不构成授权。

## 领域逻辑（`src/`）

- `registry.js` — 项目/机构查询；获奖≠许可；原演示环境与本地环境差异（语言、分级、出境规则）比对；传感器覆盖检查。
- `pilot.js` — 七组件版本校验、四项闸门状态、真实值守准入判定、状态一致性。
- `degradation.js` — 触发→最严模式解析、置信度阈值匹配、接管覆盖与留痕字段校验。
- `sharing.js` — 授权 + 双白名单 + 禁出字段过滤；本地等级代码转跨国 `severity_rank`。
- `drill.js` — 台风相位/时间偏移顺序、注入点、降级接管闭环、跨境输出合规的演练评估。
- `timeline.js` — UTC 稳定排序、台风链顺序、撤回即时冻结、逐国扩大推广证据判定。
