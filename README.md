# 东盟应急项目试点

描述跨国应急科技试点的适配、演练和运行边界。

## 领域资料

- `contracts/context.schema.json` 定义共享资料格式，`fixtures/context.json` 提供可公开使用的虚构样例。
- `contracts/pilot-product.schema.json` 定义**跨国台风洪涝试点产品**格式，`fixtures/pilot-product.json` 是对应的七国虚构样例。

领域资料按版本保存参与者、事实与约束，代码中的读取器负责检查必要字段。所有样例均为虚构，不含真实个人信息、账号、密钥或连接凭据。

当前资料反映以下业务事实：

- 项目面向监测预警、应急救援和安全生产
- 越南等国家希望开展本地试点
- 极端天气和区域公共安全是共同挑战

## 跨国试点产品结构

获奖参赛项目（`source_project`）被组织为可本地部署的试点产品，七类工件各自独立版本化，部署只能按精确版本钉用：

| 工件族 | 内容 |
| --- | --- |
| `technical_capability` | 技术能力（含自动化等级与降级阈值） |
| `training_data_boundary` | 训练数据边界（来源、语言/地域覆盖、禁用情形） |
| `equipment_dependency` | 设备与网络依赖 |
| `deployment_site` | 部署地点 |
| `responsible_organization` | 责任机构 |
| `drill_script` | 演练脚本 |
| `acceptance_metric` | 验收指标 |

其余部分：

- `organizations`：七国机构资料与各自时区联系窗口。
- `country_profiles`：每国独立掌握本地风险与处置——语言界面授权、灾种分级映射（演示 D1-D4 ↔ 本地等级）、传感器条件、数据出境规则。
- `deployments`：部署状态（`blocked_pre_gate` / `parallel_shadow` / `live_duty` / `suspended` / `withdrawn`）、钉版工件、责任机构与四道闸门。
- `drills`：演练脚本引用、按 UTC 排序并附本地时间的台风事件序列（形成→逼近→登陆→洪涝→减弱）、故障注入与验收指标引用。
- `operations`：网络中断/传感器漂移/置信度下降的自动降级事件（L3→L2→L1→L0）与人工接管留痕。
- `cross_border_sharing`：跨境只共享获准的预警摘要。
- `governance`：多方签署（UTC 与本地时间双记录）、资金里程碑、成果撤回及级联失效、主办方推广决定。

## 强制规则（由 `src/product.js` 校验，`test/product.test.js` 覆盖正反例）

1. **获奖不是上线许可**：`award_is_operational_license` 恒为 false。
2. **四道闸门缺一不可**：本地化评审、数据授权、人员培训、回退方案全部通过才允许 `live_duty`；闸门与国家档案（语言授权、出境授权）必须一致。
3. **钉版与适用范围**：部署必须钉齐七族工件的现行（issued）精确版本，且该版本声明适用于该国。
4. **自动降级只降不升**（恢复事件除外），进入 L0 仅人工模式必须留下人工接管记录；接管人须是本部署责任机构的持证人员。
5. **真实事件演练**的故障注入必须与实际自动降级事件一一对应（触发因、UTC 时间、目标等级）；桌面/功能/模拟演练不得冒充真实证据，影子运行与被拦截站点不得产生真实值守证据。
6. **台风事件顺序**：UTC 时间严格递增，阶段不得颠倒，事件须落在演练时间窗内。
7. **跨境共享**：类别只能是 `approved_alert_summary`，且共享已授权、发送国出境规则允许。
8. **多方签署**的本地时间必须与 UTC 和机构时区自洽。
9. **成果撤回**：工件版本撤回后，其证据对资金里程碑与推广决定全部失效。
10. **推广决定只能依据证据**：扩大推广必须同时具备通过的真实事件值守演练和真实运行中的自动降级证据，且证据属于本国、未撤回、时间不晚于决定。

样例中的情形：越南岘港通过四闸门后真实值守，台风 PILOT-07（虚构）中三次自动降级并人工接管，一次预警摘要获准跨境共享，主办方据证据决定扩大到越南第二站点；菲律宾仅影子运行（hold）；泰国因数据授权闸门未过被拦截（hold），相关资金里程碑冻结。
