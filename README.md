# 东盟应急项目试点

描述跨国应急科技试点的适配、演练和运行边界。

## 领域资料

`contracts/context.schema.json` 定义共享资料格式，`fixtures/context.json` 提供可公开使用的虚构样例。领域资料按版本保存参与者、事实与约束，代码中的读取器负责检查必要字段。

当前资料反映以下业务事实：

- 项目面向监测预警、应急救援和安全生产
- 越南等国家希望开展本地试点
- 极端天气和区域公共安全是共同挑战

## 本地校验

运行项目自带测试可确认样例资料能够读取，且领域标识、版本和事实记录完整。样例不含真实个人信息、账号、密钥或连接凭据。
